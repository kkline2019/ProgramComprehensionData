# Reproducing The Impact of Names on Program Comprehension Experiment Results
## Overview

This repository contains all materials needed to understand and verify the results of this experiment.
This experiment studied how naming choices affect programmers' ability to comprehend programs.

Because this study involved human subjects completing tasks manually, no computational pipelines
or executable code is required to reproduce the results. Instead this repository provides:
- The participants raw data
- A description of how the data was processed
- The calculations used to produce the reported means, t-test, and figures.
